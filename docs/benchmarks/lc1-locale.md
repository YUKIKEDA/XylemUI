# LC1: 文字を作る経路とロケール

行 LC1（Issue #849）は、言語を指定しない文字を作る時に、いちばん近くで置かれたロケールを文脈から 1 回引くようにした（設計書 §4.11「文字の既定の言語」）。文字 1 つごとの Effect は作らない。Windows 11 26300、Intel Core i5-13400F、NativeAOT の Release で測った。

## 再現

```powershell
dotnet publish benchmarks/XylemUI.E2E -c Release -r win-x64 -o <dir>
cmd /c start "" /affinity 4 /high /wait /b <dir>\XylemUI.E2E.exe todo
```

- **順:** main（`c06400a`）と LC1（`ced53d8`）を、main・LC1・LC1・main の順で 2 巡（4 回ずつ）
- **負荷:** ほかのプロジェクトのテストが動いていて、各回の直前の CPU の負荷は 25.9〜52.4 % だった。待たずに測った
- **値:** 4 回の中央値。かっこの中は最小〜最大

## `todo` の変更の段（µs、1,000 項目）

| 段 | main | LC1 |
| --- | --- | --- |
| 足す | 34.35（32.9〜36.2） | 35.55（35.2〜50.8） |
| 済みにする | 39.50（39.4〜55.2） | 40.15（39.7〜60.6） |
| 消す | 38.15（37.7〜54.9） | 36.75（36.6〜57.4） |
| 絞り込む | 23.80（22.2〜48.4） | 21.70（21.2〜22.4） |
| 絞り込みを戻す（行を 35 個作る。行ごとに文字がある） | 21.35（20.2〜30.0） | 20.00（19.9〜20.1） |
| 逆順 | 24.00（22.9〜31.1） | 23.30（23.2〜23.4） |

- **文字を作る段（絞り込みを戻す）は、長くなっていない。** main と LC1 の範囲は重なる
- どの段も、この負荷では main と LC1 の差を読めない。足す段の中央値の差（1.2 µs）は、範囲が重なる。この段は行を作らない（行 Q14 の Todo の値と同じ場面）
- 文字だけを大量に作る場面（`text`）は、この負荷で 1 回に 174 秒かかったので、流すのをやめた。文字 1 つを作る時間そのものは測っていない

## 大きさ

- 実行ファイル: 7,759,360 → 7,832,064 バイト（+72,704。登録簿から作った表と、タグを読むコード）
- 文字の葉（`TextLeaf`）: 参照が 1 つ増えて +8 バイト
