# I1b: タッチとペンのドラッグでのスクロールと慣性

タッチとペンのドラッグでスクロールする箱を動かし、離したときの速さで慣性をつけて流すようにした（ロードマップの行 I1 の I1b、Issue #396、設計書 §7「タッチとペン」、§2.11「フレームの時刻」）。どれも Windows 11 26300、Intel Core i5-13400F、NativeAOT の Release で、性能コア（論理プロセッサ 2）に固定し、優先度を高くして測った。比べた main は、ブランチの土台の 20bc4af である。2 つの実行ファイルのハッシュが違うことを確かめてから測った。

## 再現

```powershell
dotnet publish benchmarks/XylemUI.E2E -c Release -r win-x64 -o <dir>
cmd /c start "" /affinity 4 /high /wait /b <dir>\XylemUI.E2E.exe input
```

`input` の場面は、ウィンドウを開かない。I1b で次の 3 つを足した。

- **タッチのドラッグの move:** ホイールの場面の箱（高さ 300、中身 3,000）を、ドラッグしているタッチが 1 画素ずつ上と下に交互に動かす（`us_per_touch_drag_move`）
- **慣性の 1 フレーム:** 中身が 100,000 の箱を 8,000 画素毎秒で流し、0.05 ms ずつ進めたフレームの時刻で 1 歩ずつ位置を決める（`us_per_fling_frame`）。終わりにも端にも着かない
- **フレームの時刻の読み出し:** `TimeProvider.System.GetElapsedTime(0)` の 1 回（`us_per_frame_time_read`）。`WindowFrames.RunFrame` が、フレームの始めに 1 回読む

## タッチのドラッグと慣性（I1b の 4 回、21 標本の中央値）

| 指標 | I1b | 比べる指標（I1b） |
| --- | --- | --- |
| タッチのドラッグの move | 0.094〜0.100 µs | ホイール: 0.093〜0.100 µs |
| 慣性の 1 フレームの位置の更新 | 0.052〜0.057 µs | — |
| フレームの時刻の読み出し | 0.021〜0.024 µs | — |

- タッチのドラッグの move は、位置を変える 1 回のホイールと同じ程度である。どちらも、経路を作って配り、`ScrollState` の位置を 1 回書く
- 慣性の 1 フレームは、式を 1 回解き（`Math.Pow` が 1 回）、位置を書く。フレームの時刻の読み出しと合わせて、1 フレーム 0.08 µs ほどである

## マウスとキー（main と交互に 4 回、21 標本の中央値）

| 指標 | main | I1b |
| --- | --- | --- |
| move、深さ 1 | 0.143〜0.161 µs | 0.146〜0.164 µs |
| move、深さ 50 | 4.23〜4.62 µs | 4.25〜4.56 µs |
| ホバーが変わる move | 0.186〜0.195 µs | 0.187〜0.194 µs |
| クリック | 0.310〜0.348 µs | 0.312〜0.324 µs |
| ホイール | 0.092〜0.101 µs | 0.093〜0.100 µs |
| キー、深さ 50 | 1.72〜2.51 µs | 1.67〜1.72 µs |
| スクロールするキー | 0.085〜0.092 µs | 0.084〜0.095 µs |
| Tab（10,101 ノード） | 159〜172 µs | 160〜170 µs |
| タッチのタップ | 0.297〜0.322 µs | 0.292〜0.300 µs |
| ペンの move、深さ 1 | 0.143〜0.161 µs | 0.144〜0.163 µs |
| ペンの move、途中の点 8 つ | 0.180〜0.184 µs | 0.191〜0.202 µs |

- ペンの move の途中の点 8 つのほかは、範囲が重なる
- **ペンの move の途中の点 8 つ:** この回は I1b が 0.01 µs 長かった。順を I1b、main、main、I1b に変えた次の回（4 回）は、main 0.182〜0.201 µs、I1b 0.185〜0.209 µs で重なった。この経路で I1b が足したのは、触れていないペンの move が通る 2 つの判定（ドラッグの候補か、速さの点を足すか）だけで、深さ 1 のペンの move（0.143〜0.161 µs と 0.144〜0.163 µs）は重なる

## 割り当て

- Core: 位置を 0 に戻し、1,000 画素毎秒で上へ払い、慣性のフレームを終わりまで回すことを 1,000 回して 0 バイト（`TouchScrollTests.SteadyState_DragAndFling_AllocateNothing`）。速さの追跡器はポインタの状態ごとに 1 つで、最初の押下で作る。ドラッグの状態は使い終わったものを使い回す
