# L9: GPUI のレイアウトを Taffy 0.13.0 で比べる

比較の「GPUI」を、Zed が出荷している Taffy 0.13.0 にした（ロードマップの行 L9、Issue #139）。これまでの 0.9.0 は crates.io の gpui 0.2.2（2025-10-22）が固定している版で、GPUI を使って出荷されている製品の版ではなかった。Zed の最新の安定版 v1.24.3（2026-10-19）の `Cargo.toml` は `taffy = { version = "=0.13.0", default-features = false }`。

## 測った物と機械

- コミット: このファイルを加えたコミット（`git log -1 -- docs/benchmarks/l9-taffy-0.13.md`）
- 機械と作り方: L1a と同じ（`docs/benchmarks/l1a-layout.md`）。XylemUI は NativeAOT
- 版（`build.ps1` が書く `versions.json`）: Flutter 3.47.7、Avalonia 12.1.4、Taffy 0.13.0。Flutter は `elapsedTicks` から測る（L7、PR #138）
- `benchmarks/compare/layout.ps1` で 4 つを 5 ラウンド交互に。表はラウンドの中央値と最小〜最大（µs）

## 再現

```powershell
$env:PATH += ';C:\Program Files (x86)\Microsoft Visual Studio\Installer'
./benchmarks/compare/build.ps1 -Out <dir>
./benchmarks/compare/layout.ps1 -Built <dir> -Rounds 5
```

- **XylemUI と GPUI（Taffy 0.13.0）**: 絶対配置の子の場面の最初の layout のほかは、XylemUI が 1.4〜10.4 倍速い。絶対配置の子の場面の最初の layout は Taffy が 7 % 速い（L2 と同じく、XylemUI は 1 万個の絶対配置の子を、子ごとに測るだけの実行と layout の実行で 2 回求める）
- **Taffy 0.9.0 から 0.13.0 で遅くなった**: 同じ日に 0.9.0 で測った回（L7、PR #138）では、S6b の意味の最初の layout 7,144 µs、1 か所の変更 56.1 µs、幅の変更 4,571 µs だった。比較のアプリが数える葉の計測の回数も、最初の layout で 60,000 回から 110,000 回、1 か所の変更で 6 回から 305 回に増えた。遅くなったのは Taffy の側の計算の回数で、XylemUI の数字は変わらない
- Flutter と Avalonia の値は L7 の測り直し（PR #138）と同じ範囲

## 設計書の主張の確かめ直し（0.13.0 のソース、crates.io の `taffy-0.13.0`）

| 設計書の主張（「GPUI が使う Taffy 0.9.0」を根拠にしたもの） | 0.13.0 |
| --- | --- |
| 絶対配置の子は親を基準に置く（§3.2「L2 の方式」） | 成り立つ。`compute/flexbox.rs` と `compute/block.rs` の `perform_absolute_layout_on_absolute_children` が、容器の大きさ（`container_size`）から置く |
| `FlexWrap` は NoWrap・Wrap・WrapReverse だけ（§3.2、行 L6） | 成り立つ（`style/flex.rs`） |
| `Dimension` は長さ・`%`・`auto` だけ（§3.2「L3 の方式」） | 成り立たない。`min-content`・`max-content`・`fit-content`・`fit-content(px / %)` を持ち（`style/compact_length.rs`）、`min_size` / `max_size` も `Size<Dimension>`（`style/mod.rs`）。`stretch` は持たない |
| `safe` / `unsafe` を持たない（§3.2「L1b の受け入れ」） | 成り立たない。`AlignmentSafety` を持つ（`style/alignment.rs`） |
| XylemUI は GPUI より 2〜8 倍速い（§3.2「性能の受け入れ」） | 上の表のとおり 1.4〜10.4 倍。絶対配置の子の場面の最初の layout だけ Taffy が 7 % 速い |
